# README — Building vibrationally averaged He–CO₂ effective potentials from NITROGEN VSCF (TARGET states + NC_TRANS) and running BOUND

This workflow generates **state-specific effective intermolecular potentials**
\[
V_\mathrm{eff}^{(v)}(R,\theta)=\langle \psi_v(q) | V_\mathrm{int}(R,\theta;q) | \psi_v(q)\rangle
\]
using **NITROGEN VSCF modals** and the **NC_TRANS** coordinate mapping, and then uses **BOUND** to compute bound-state levels on each effective surface.

---

## 0) Files you need (per isotopologue)

From NITROGEN:
- `NC_TRANS`  
  (generated by the STAT/FREQ job used as `COORD_TRANS` in the VSCF job)
- `VSCF_MODES_TARGET000.dat`  
  (ground target, typically `TARGET = 0,0,0,0,0,0`)
- `VSCF_MODES_TARGETXXX.dat`  
  (your *excited* target for v3; e.g., `TARGET` with 1 quantum in the v3 coordinate)

From your scripts/tools:
- `extract_vscf_target.py`  
  Reads `VSCF_MODES_TARGET*.dat` and writes NPZ files containing `grid` and `psi`.
- Your averaging script (e.g., `averaging_nitrogen.py`) that:
  - uses NC_TRANS inversion
  - builds geometries in **angstrom**
  - evaluates your PES consistently in **angstrom**
  - outputs `Veff` grids in the format your VRTP/BOUND expects

From BOUND:
- BOUND executable + input files
- your `VRTP` interpolator routine reading a `Veff` grid file

---

## 1) Run NITROGEN STAT/FREQ (once per isotopologue coordinate definition)

Goal: produce `NC_TRANS` that defines your **transformed coordinates** (curvilinear normal coordinates).

Typical job includes:
- `JOBTYPE = JOBTYPE_STAT`
- `STAT_TYPE = MIN`
- `CALC_FREQ`
- `COORD = ZMAT` (your ZMAT)
- (optional) `CALC_RECT` if you want rectilinear output, but for this workflow we use `NC_TRANS`

Output:
- `NC_TRANS`

**Important:** keep this `NC_TRANS` paired with the VSCF job that uses it.

---

## 2) Run NITROGEN VSCF (per isotopologue)

Goal: produce VSCF modal files for the relevant TARGET states.

Your VSCF job should include:
- `JOBTYPE = JOBTYPE_VSCF`
- `COORD = ZMAT`
- your `%ZMAT ... %`
- `COORD_TRANS = NC_TRANS`
- `Q1..Q6 = AC HO 15 -5 5` (or higher N if you want denser DVR sampling)
- `TARGET_MAXV = 3` (or as needed)
- `REF1 = 0 0 0 0 0 0`

Outputs:
- `VSCF_MODES_TARGET000.dat` (ground target)
- `VSCF_MODES_TARGETXXX.dat` (excited target you will use for v3=1 averaging)

**Note on resolution:** if you want more than 15 DVR points, increase `HO 15` → `HO 31/41/...` and consider reducing the coordinate range `-5 5` → `-3 3`.

---

## 3) Extract the VSCF modal wavefunctions (NPZ)

Use `extract_vscf_target.py` to create NPZ files containing:
- `grid` (the DVR grid values for the selected coordinate)
- `psi`  (the modal values on that grid)

### 3.1 Identify which mode corresponds to v3
From your `--summary`, **mode 6** typically matches CO₂ ν3 (~2340 cm⁻¹ spacing).

### 3.2 Extract ground-state modal (v3 = 0)

```bash
python extract_vscf_target.py VSCF_MODES_TARGET000.dat --mode 6 --col 0 --out q3_v0.npz
```

### 3.3 Extract excited-state modal (v3 = 1)

```bash
python extract_vscf_target.py VSCF_MODES_TARGETXXX.dat --mode 6 --col 1 --out q3_v1.npz
```

Sanity check:
- your extractor should report `sum|psi|^2 ≈ 1` for both files.

---

## 4) (Optional but recommended) Validate the coordinate mapping with NC_TRANS

Generate an XYZ scan to confirm you can map DVR points → Cartesian geometries:

```bash
python dvr_to_xyz_zmat_nctrans.py --npz q3_v0.npz --nctrans NC_TRANS --coord 6 --out mode6_scan.xyz --print_q0
```

Checks:
- **He–C distance R12** should be nearly constant across the scan (minimal mixing into intermolecular coordinates).
- **CO bond lengths** should behave like an antisymmetric stretch: one increases while the other decreases.
- Endpoint geometries can look extreme; what matters is their small probability weights.

---

## 5) Build vibrationally averaged effective grids Veff(R,θ)

Use your adapted averaging script (now fixed so the PES is called with **angstrom**).

That script should:
- load `q3_v0.npz` and `q3_v1.npz`
- compute weights as `w = |psi|^2` (no `dq_bohr`)
- invert `NC_TRANS` to convert `q'` → ZMAT variables at each DVR point
- construct the CO₂ geometry for each DVR point (COM-fixed for the isotopologue)
- place He at Jacobi `(R,θ)` relative to the CO₂ COM/axis
- evaluate `V_int(R,θ;q)` using your PES (**angstrom** input)
- average over the q-grid to produce `Veff0(R,θ)` and `Veff1(R,θ)`

Example run:

```bash
python averaging_nitrogen.py
```

Outputs (examples):
- `Veff0_grid.dat`
- `Veff1_grid.dat`
- optionally `Veff_grids_from_NITROGEN.npz`

### Critical sanity check (repulsive wall)
At small `R` and acute angles, Veff should become strongly repulsive.  
If not:
- confirm the PES expects **angstrom** (not bohr)
- confirm atom ordering matches what the PES expects

---

## 6) Prepare BOUND potential input (VRTP)

BOUND reads the potential through your VRTP routine.

For each effective surface you want to run:
- point VRTP to the corresponding grid file:
  - `Veff_v0` grid file for lower state
  - `Veff_v1` grid file for upper state

Recommended naming:
- `Veff_626_v0.dat`, `Veff_626_v1.dat`
- `Veff_636_v0.dat`, `Veff_636_v1.dat`
- etc.

Make sure the grid format matches what VRTP expects (same R list, same θ list, consistent units).

---

## 7) Run BOUND (per isotopologue, per vibrational-state surface)

You typically run BOUND twice per isotopologue:
1) with `Veff_v0(R,θ)` → bound-state levels for v3=0 surface
2) with `Veff_v1(R,θ)` → bound-state levels for v3=1 surface

### What you must update for each isotopologue
- Mass parameters / reduced mass (He + CO₂ isotopologue)
- CO₂ rotational constant (and if you want high precision, use the appropriate B for each vibrational state)
- VRTP pointer to the correct Veff grid file

### What usually stays the same
- BOUND method settings (basis size, J range, convergence settings), unless you were using symmetry restrictions that change for asymmetric isotopologues
- VRTP interpolation logic (if the grid format is consistent)

### Band-origin shift (basic)
Compute the shift by comparing appropriate bound-state energies between the two runs, e.g.:
\[
\Delta \nu_0 \approx \left[E_\mathrm{bound}^{(v_3=1)} - E_\mathrm{bound}^{(v_3=0)}\right]
\]
(Details depend on your chosen reference level and quantum assignments.)

## Quick checklist (when something looks wrong)

- [ ] Are you using **mode 6** for ν3?
- [ ] Are `q3_v0.npz` and `q3_v1.npz` on the **same DVR grid**?
- [ ] Are weights computed as `|psi|^2` (no `dq_bohr`)?
- [ ] Is `NC_TRANS` the one used by your VSCF job?
- [ ] Is the PES being called with **angstrom** coordinates (not bohr)?
- [ ] Does the potential show a **repulsive wall** at small R?
- [ ] In BOUND, did you update masses/rotational constants for the isotopologue?
- [ ] Are you sure VRTP is reading the intended Veff file for that run?
